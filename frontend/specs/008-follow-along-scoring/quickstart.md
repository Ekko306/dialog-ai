# Quickstart: 循环跟读录音评测（008）

> 前置：`pnpm dev:backend` + `pnpm dev:frontend`（须用 http://localhost:3000，录音需安全上下文）；先在对话页完成一次语音输入产生纠错气泡。

## §1 录音评测闭环（US1，P1）

1. 点纠错气泡操作栏「循环跟读」→ 面板弹出，正确句全文 + 示范播放可用
2. 点麦克风 → **面板内**出现录音操作区（含跟读句、开始按钮、× 取消）；若示范播放中应已被暂停
3. 点开始 → 朗读跟读句 → 点结束 → 出现「评测中…」
4. **预期**：约 1~2s 后展示评分视图——逐词着色的跟读句（绿/黄/红 + ⚠ 角标）、综合评分徽章、流利度/发音分/完整度三行分数条、虚线分隔文字建议（与发音逐词分析面板同风格）
5. 点 × 关闭录音区可取消，无残留

## §2 重读与我的（US2，P2）

1. 在评分视图点「重读」（评分建议标题行）→ 回到录音操作区 → 再录一轮
2. **预期**：新分数/着色/建议**覆盖**旧值，无残留
3. 点控制排「我的」→ 播放**自己刚才的录音**；再点示范播放 → 两者互不叠音
4. 关闭面板后重新打开「循环跟读」→ **预期**：回到干净待录音状态（上轮评分与录音不显示）；打开纠错气泡「发音」面板 → 其评测结果与跟读轮无关（缓存隔离红线，契约 §1）

## §3 示范标签单项化（US3，P3）

1. 打开跟读面板看控制排语言组：**仅「英语(美)」一个标签**，无英语(英)/中文
2. 播放（美音）、切语速 0.75x/1x/1.25x、开关循环 → 行为与改造前一致

## §4 降级与异常

| 操作 | 预期 |
|---|---|
| 拒绝浏览器录音权限后点麦克风 | 录音区显示权限提示，可重试/关闭，面板其余正常 |
| 点开始后立刻结束（<1s） | 「录音太短」提示，不发起评测 |
| 断网后完成录音 | 「评测失败」+ 重新评测按钮；恢复网络点重试可成功 |
| 无录音时点「我的」 | 按钮禁用态，无响应无报错 |
| 录音中途直接关面板 | 麦克风立即释放（浏览器录音指示消失），重开无残留 |
| 文本框输入产生纠错后打开跟读 | 跟读评测仅用本地录音，无「未找到本次录音」类提示（与 007 首评降级路径无关） |

## §5 零回归（SC-004）

- 纠错气泡：文/A 翻译、示范句播放、语法纠正展示
- 润色气泡：润色结果、「地道」弹窗（仅语境润色）
- 纠错「地道」弹窗：发音逐词分析 + 评分建议 + 语境润色三区块完整
- 语速仪表盘：不做，评分视图无仪表盘为**预期行为**（spec Assumption）
