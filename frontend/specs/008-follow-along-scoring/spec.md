# Feature Specification: 循环跟读录音评测（开始跟读 → 综合评分）

**Feature Branch**: `008-follow-along-scoring`

**Created**: 2026-10-28

**Status**: Draft

**Input**: User description: "把循环跟读的英音和中文去掉；另外开始做「开始跟读」这个按钮，点击之后弹出一个用户录音功能，结束以后弹出综合评分界面（用户会话截图二）。这里应该是和发音逐词分析的重读功能是一样的流程。最好不要改动我的所有后端代码。还是用 speckit。"

**视觉基准**：用户会话截图两张（2026-10-28，未入库）——图一：现有跟读面板（示范播放 + 三语种标签 + 麦克风按钮）；图二：录音结束后的综合评分界面（逐词着色原句 + 播放行 + 语速选择行 + 综合评分徽章 + 三项分数条 + 语速仪表盘 + 虚线分隔文字建议 + 底部重读按钮与「我的」按钮）。按用户明确要求截图不加入 docs/mockups/，本 spec 以文字记录截图要点作为对照基准。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 开始跟读录音并查看综合评分 (Priority: P1)

用户在循环跟读面板中点击「开始跟读」麦克风按钮，面板内展开录音操作区（展示跟读参考句）；用户朗读参考句后结束录音，系统对录音发起发音评测（对照跟读文本），约 1~2 秒后在面板内展示综合评分界面：逐词着色的跟读原句（绿/黄/红同既有逐词分析规则）、综合评分徽章、流利度/发音分/完整度三行分数条、虚线分隔的文字建议。全程不离开跟读面板、不产生新对话消息。

**Why this priority**: 这是本功能的核心价值闭环——用户跟读后立即获得可量化的反馈；没有它「开始跟读」按钮只是一个摆设。

**Independent Test**: 打开任意循环跟读面板 → 点麦克风 → 录音并结束 → 面板内出现综合评分界面，可完全独立验证。

**Acceptance Scenarios**:

1. **Given** 跟读面板已打开且示范音频可播，**When** 用户点击麦克风按钮，**Then** 面板内展开录音操作区（含跟读参考句、开始/结束控制），再次点击或点击收起可取消且无残留
2. **Given** 录音操作区已展开，**When** 用户完成一段正常时长的朗读并点击结束，**Then** 出现「评测中…」加载反馈，随后面板内填充综合评分界面
3. **Given** 评分界面已展示，**When** 用户对照逐词着色与分数条查看，**Then** 着色规则与发音逐词分析一致（≥85 绿 / 70~85 黄 / <70 红 / 无分不着色），四项分数为百分制真实评测值

---

### User Story 2 - 重读再评与我的录音回放 (Priority: P2)

评分界面提供两个后续操作：「重读」按钮再次进入录音流程，新录音重新评测后评分界面整体刷新为最新结果；「我的」按钮回放用户自己刚录的音频，帮助用户对照示范与自身读音。评测结果与录音仅在当前面板会话内有效，不回写对话线程、不产生气泡变化。

**Why this priority**: 重读是「练-评-再练」闭环的关键一环（用户 2026-10-27 已在 007 明确同一交互心智：「点重读 → 弹录音 → 重新评分 → 评分建议重新更新」）；「我的」回放是低成本高感知的辅助能力。

**Independent Test**: 在 US1 的评分界面上点「重读」→ 重新录音 → 新分数覆盖显示；点「我的」→ 听到自己的录音。

**Acceptance Scenarios**:

1. **Given** 评分界面已展示，**When** 用户点「重读」并完成新一轮录音，**Then** 综合评分、分数条、逐词着色与文字建议全部刷新为新录音的评测结果（覆盖旧值）
2. **Given** 本轮面板内已有用户录音，**When** 用户点「我的」，**Then** 播放用户自己的录音（与示范播放相互独立，不串音）
3. **Given** 用户关闭跟读面板后重新打开，**When** 查看评测状态，**Then** 上轮评测结果与录音不再展示（面板会话内有效），从干净的待录音状态开始

---

### User Story 3 - 示范播放仅保留英语(美) (Priority: P3)

跟读面板示范播放的语种标签栏删除「英语(英)」「中文」两个选项，仅保留「英语(美)」单项，与用户 2026-10-27 对发音逐词分析（仅美音）的拍板保持一致。语速选择与循环开关行为不变。

**Why this priority**: 纯 UI 精简、价值明确但体量极小；用户明确点名要求，随手可做。

**Independent Test**: 打开跟读面板即可验证标签栏仅剩英语(美)，示范播放正常。

**Acceptance Scenarios**:

1. **Given** 跟读面板已打开，**When** 用户查看示范播放标签栏，**Then** 仅显示「英语(美)」一个标签，无英音/中文选项
2. **Given** 标签栏单项化后，**When** 用户点击播放、切换语速、开关循环，**Then** 行为与改造前一致（仅美音播放）

---

### Edge Cases

- 用户点击麦克风后拒绝浏览器录音权限 → 录音操作区内展示明确权限提示，可重试可关闭，面板其余部分不受影响
- 录音时长过短（不足有效评测长度）→ 提示「录音太短，请重新朗读」，不发起评测
- 评测请求失败或评测被拒（读的内容与参考句不符等）→ 展示失败原因与「重新评测」行内重试（重发同一段录音），不打断面板
- 录音进行中用户直接关闭面板或点击收起 → 立即释放麦克风、丢弃未完成的录音，无报错无残留
- 用户从未录音时点「我的」→ 按钮不可用（不发声、不报错）
- 录音开始时示范音频仍在循环播放 → 自动暂停示范播放，避免示范声混入录音影响评分
- 环境不支持录音（非安全上下文等）→ 录音操作区展示不可用原因，不伪造成可录音状态

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 跟读面板 MUST 在点击麦克风按钮后在面板内展开录音操作区，展示跟读参考句与开始/结束/取消控制（不弹独立窗口、不跳转）
- **FR-002**: 系统 MUST 在用户结束录音后自动对该录音发起发音评测，评测对照文本 = 当前跟读参考句，评测链路复用现有按需评测端点（后端零改动）
- **FR-003**: 评测进行中 MUST 展示加载反馈，评测失败 MUST 展示失败原因并提供行内重试
- **FR-004**: 综合评分界面 MUST 包含：逐词着色的跟读原句、综合评分徽章、流利度/发音分/完整度三行分数条（条长映射百分制分值）、虚线分隔的文字建议；着色与分数条配色沿用既有逐词分析规则
- **FR-005**: 评分界面 MUST 提供「重读」入口，触发新一轮录音-评测，新结果覆盖旧结果展示
- **FR-006**: 评分界面 MUST 提供「我的」回放入口，播放本轮面板会话内的用户录音；无录音时不可用
- **FR-007**: 示范播放标签栏 MUST 仅保留「英语(美)」单项，删除「英语(英)」「中文」选项
- **FR-008**: 用户录音 MUST 仅在当前面板会话内保留，评测结果 MUST NOT 回写对话线程、气泡或任何消息级数据
- **FR-009**: 录音开始时系统 MUST 暂停示范音频播放；录音结束/取消后不自动恢复（由用户手动控制）
- **FR-010**: 权限被拒、录音过短、评测失败、设备不支持等异常 MUST 有明确中文提示且均可退出，面板整体不进入死状态
- **FR-011**: 本功能 MUST NOT 修改任何后端代码（评测端点、解析函数、图与节点均复用 007 现状）

### Key Entities *(include if feature involves data)*

- **跟读评测会话（面板内）**: 一轮「录音 → 评测结果 → 用户录音」的临时数据，生命周期 = 跟读面板本次打开；包含用户录音（16kHz 单声道 PCM）与评测结果（综合/流利度/发音分/完整度 + 逐词分与标记）
- **评测结果**: 结构同既有发音评测（四项百分制分数 + 逐词着色数据），复用 007 契约，不新增字段

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户从结束录音到看到综合评分界面的等待不超过 3 秒（评测请求 1~2 秒 + 渲染）
- **SC-002**: 评分界面的着色规则、分数条样式、虚线分隔与文字建议同发音逐词分析面板视觉一致（同一套展示风格）
- **SC-003**: 重读一轮后评分界面全部数值与着色刷新为新录音结果，旧值无残留
- **SC-004**: 003~007 全部既有验收场景（纠错气泡、翻译、润色、地道面板、发音逐词分析）零回归
- **SC-005**: 示范播放标签栏仅剩英语(美)一项，语速与循环功能行为不变

## Assumptions

- **语速仪表盘（图二右侧圆弧仪表）v1 不实现**：语速数据依赖讯飞评测 XML 中当前解析链路未透出的字段，在「后端零改动」约束下无数据来源；评分界面以分数条 + 文字建议呈现（与 007 评分区块一致）。若后续放开后端约束可在 008 追加
- 评测链路、录音采集、评分展示均复用 007 已交付能力（评测端点、PCM 采集工具、评分区块风格），本功能为前端装配层工作
- 「我的」回放仅限本轮面板会话内录音（面板关闭即失效），不做跨会话保存
- 逐词着色的分词与着色数据来自评测返回的逐词结果（评测对象 = 跟读参考句分词）
- 录音操作采用「点击开始/点击结束」模式（与 007 重读一致）；用户会话中确认流程「和发音逐词分析的重读功能是一样的」
- 循环跟读面板既有能力（语速 0.75x/1x/1.25x、循环开关、示范播放）保持不变，仅标签栏单项化
