## Clarifications

### Session 2026-10-24

- Q: 点击「‼ 语法纠错」标签收起讲解后，气泡里应该保留哪些内容？ → A: 收起态仅保留**原句行 + 功能行（文A | ‼ 语法纠错 ⌄ | AI 发音）**；讲解内容、✅ 正确句、底部操作栏（循环跟读/复制/收藏/AI 发音）全部隐藏（用户提供收起态截图为验收基准：紧凑绿底气泡，仅两行）。
- Q: AI 回复刚到达时，纠错气泡应该默认是收起态还是展开态？ → A: **默认展开态**——刚收到时即显示讲解 + ✅ 正确句 + 底部操作栏（与原型图一致），用户可点击「‼ 语法纠错」收起为紧凑两行态。
- Q: 音频互斥的范围是只在同一条气泡内，还是整个页面全局互斥？ → A: **全局互斥**——任何时刻整页最多一段音频在播（含跟读面板），开始新的播放自动停止旧的，避免多条气泡声音叠加。
- Q: 评分条上「发音分析 >」「更多地道 >」入口点击后发生什么？ → A: 本次为**静态占位**（可点击、轻提示"功能开发中"，不跳转）；其最终目标界面为 docs 中「子功能气泡-单击发音或地道」原型，属后续独立 feature，本次不实现跳转。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 纠错气泡特殊渲染与讲解展开/收起 (Priority: P1) 🎯 MVP

用户在 Tab1 主页发出一句含语法错误的英语后，AI 回复的气泡**默认按展开态**（原型图）特殊渲染：顶部为用户原句行（如"Good study, 对对啊。"）；其下为功能行——左「文A」翻译按钮、中「‼ 语法纠错 ⌃」标签、右「AI 发音」按钮；功能行之下为后端纠错讲解内容（逐条中文讲解 + 分隔线 + ✅ 开头的改正后完整句）；气泡底部为操作栏「循环跟读 | 复制 | 收藏 | AI 发音」。点击「‼ 语法纠错」标签收起为紧凑两行态（原句行 + 功能行，⌄，以用户收起态截图为基准），再次点击展开复原。普通 AI 消息（无纠错内容）保持现有气泡样式不变。

**Why this priority**: 纠错气泡是本功能的核心载体，其余所有交互按钮都存在于这个气泡内；没有它，复制/发音/跟读均无处安放。

**Independent Test**: 仅实现本故事即可演示：说一句错误英语 → 收到纠错气泡（默认展开态，与原型图一致）→ 点击「语法纠错」收起为紧凑两行 → 再点展开复原 → 普通气泡样式不受影响。

**Acceptance Scenarios**:

1. **Given** 用户位于 Tab1 主页，**When** 发送一句含语法错误的英语并收到回复，**Then** 该条 AI 气泡按原型图以展开态渲染：原句行 + 功能行（文A / ‼语法纠错 ⌃ / AI 发音）+ 讲解内容 + ✅ 正确句行 + 底部操作栏（循环跟读 / 复制 / 收藏 / AI 发音）
2. **Given** 纠错气泡处于展开态，**When** 点击「‼ 语法纠错 ⌃」标签，**Then** 收起为紧凑两行态（仅原句行 + 功能行，箭头变 ⌄，与收起态截图一致）；再次点击展开复原
3. **Given** 纠错气泡处于展开态，**When** 与原型图目视比对，**Then** 布局结构（原句行、功能行、讲解内容、✅ 正确句、操作栏按钮）与原型图一致；收起态与用户提供的收起态截图一致
4. **Given** 对话中存在普通 AI 消息（无纠错内容），**When** 查看该消息气泡，**Then** 其样式与交互和本功能上线前完全一致（零回归）

### User Story 2 - 一键复制改正后的正确句 (Priority: P2)

用户点击气泡底部操作栏的「复制」按钮，系统仅把**改正后的完整英语句子**（不是原句、不是中文讲解、不是整个气泡内容）写入剪贴板，并给出已复制反馈（如图标短暂变为对勾）。

**Why this priority**: 复制是高频轻量操作，数据（正确句）已由后端纠错气泡内容直接给出，实现成本低、用户价值直接。

**Independent Test**: 仅实现本故事即可验证：点击「复制」→ 在任意文本框粘贴 → 得到的是完整正确英语句，无多余内容。

**Acceptance Scenarios**:

1. **Given** 纠错气泡处于展开态且存在改正后的正确句，**When** 点击「复制」，**Then** 剪贴板内容为改正后的完整英语句子，且复制按钮出现成功反馈（如对勾图标）
2. **Given** 剪贴板已有纠错气泡复制的正确句，**When** 用户再次点击另一条纠错气泡的「复制」，**Then** 剪贴板更新为最新一条气泡的正确句

---

### User Story 3 - 双 AI 发音按钮（原句 / 正确句对照朗读） (Priority: P2)

用户点击功能行右侧的「AI 发音」按钮，听到**用户原句**的朗读；点击气泡底部操作栏的「AI 发音」按钮，听到**改正后正确句**的朗读。首次点击某按钮时按需触发后端语音合成（用户可感知加载状态），合成完成后自动播放；两个按钮的声音相互独立，播放其中一个时另一个停止。

**Why this priority**: 原句/正确句对照听读是口语纠错的核心学习路径，且后端语音合成旁路已具备（懒加载契约），联调价值高；但依赖音频播放基础设施，列于 P2。

**Independent Test**: 仅实现本故事即可验证：点上方 AI 按钮听到原句发音；点下方 AI 按钮听到正确句发音；播放中点另一个按钮，前一个声音停止。

**Acceptance Scenarios**:

1. **Given** 纠错气泡已展示（收起态或展开态），**When** 点击功能行的「AI 发音」按钮，**Then** 播放用户原句的朗读音频，按钮呈播放中状态（含首次合成时的加载态）
2. **Given** 纠错气泡处于展开态，**When** 点击底部操作栏的「AI 发音」按钮，**Then** 播放改正后正确句的朗读音频
3. **Given** 任一音频正在播放（原句/正确句/跟读面板均可），**When** 点击另一处「AI 发音」按钮，**Then** 旧音频立即停止，新音频开始播放（含跨气泡场景）
4. **Given** 后端语音合成失败或超时，**When** 用户点击任一「AI 发音」按钮，**Then** 展示友好失败提示，文本内容展示不受影响，可重试

### User Story 4 - 循环跟读面板 (Priority: P3)

用户点击气泡底部操作栏的「循环跟读」按钮，页面底部弹出跟读面板（对应原型图）：顶部标题「循环跟读」与关闭按钮；其下为改正后正确句全文；中部为音频进度条（当前时间/总时长）与圆形暂停/播放键；下方一排控制项——倍速切换（如 1.0x）、语言切换（英语(美) 等，展开可选英语(英)/中文等选项）、循环播放开/关切换；底部为大号麦克风跟读按钮。面板所有播放控制作用于**正确句**音频。

**Why this priority**: 跟读面板是强化练习工具，依赖 US3 的音频播放能力，价值重要但非首版核心路径。

**Independent Test**: 仅实现本故事即可验证：打开面板 → 正确句全文可见 → 播放/暂停/进度条走动 → 切倍速语速变化 → 开循环后播完自动重播 → 关闭面板回到主页且对话不中断。

**Acceptance Scenarios**:

1. **Given** 纠错气泡处于展开态，**When** 点击「循环跟读」按钮，**Then** 底部滑出跟读面板，含标题、关闭键、正确句全文、进度条、暂停/播放键、倍速/语言/循环控制项、底部麦克风按钮，主页对话在面板后方仍可见
2. **Given** 跟读面板已打开，**When** 点击暂停/播放圆形键，**Then** 正确句音频在当前进度暂停/继续，进度条与时间显示同步
3. **Given** 跟读面板已打开，**When** 选择不同倍速（如 0.75x / 1.0x / 1.25x），**Then** 播放速度随之变化且音调正常
4. **Given** 跟读面板已打开且循环开关为"开"，**When** 正确句播放完毕，**Then** 自动从头重新播放；循环开关切为"关"后播完即停
5. **Given** 跟读面板已打开，**When** 点击右上角关闭按钮，**Then** 面板收回，回到主页状态，正在进行的对话不中断
6. **Given** 跟读面板已打开，**When** 点击语言切换展开选项，**Then** 可见英语(美)/英语(英)/中文等选项；暂不可用的口音以禁用或降级提示呈现，不出现报错

### User Story 5 - 「文A」翻译展示 (Priority: P3)

用户点击气泡功能行的「文A」翻译按钮，气泡内展开显示该句的中文翻译区域；再次点击收起。翻译数据来源与展示形态遵循现有后端契约的最小适配。

**Why this priority**: 翻译辅助理解有明确价值，但后端当前无现成翻译输出，需要后端最小适配（或在数据缺失时先呈现占位），列于 P3。

**Independent Test**: 仅实现本故事即可验证：点击「文A」→ 展开翻译区域（有译文数据时显示译文；无数据时显示明确的暂无翻译提示而非报错）；再次点击收起。

**Acceptance Scenarios**:

1. **Given** 纠错气泡已展示，**When** 点击「文A」按钮，**Then** 气泡内展开翻译区域并显示该句中文翻译（或明确的暂无翻译提示），按钮呈激活态
2. **Given** 翻译区域已展开，**When** 再次点击「文A」按钮，**Then** 翻译区域收起，气泡布局恢复

---

### User Story 6 - 气泡下方评分条展示 (Priority: P3)

纠错气泡与下一条 AI 消息之间展示评分条（对应原型图）：「语法纠错!! 继续加油」「发音 82 发音分析 >」「地道 85 更多地道 >」三项评分标签，数据来自后端检查结果。某项评分数据缺失时该项不展示，评分条整体无数据时不渲染。

**Why this priority**: 评分条是学习激励与入口导流（发音分析/更多地道），但属展示型信息，不影响核心纠错路径。

**Independent Test**: 仅实现本故事即可验证：有评分数据时评分条按原型图展示且数值与后端一致；无数据时评分条不出现且布局不错乱。

**Acceptance Scenarios**:

1. **Given** 后端返回了含评分的纠错结果，**When** 纠错气泡展示，**Then** 气泡下方按原型图展示语法/发音/地道评分标签，数值与后端数据一致
2. **Given** 后端未返回某项评分（如无发音评测数据），**When** 纠错气泡展示，**Then** 该项标签不展示，其余项正常，布局不错乱

---

### Edge Cases

- 后端未返回改正后正确句（修正清单为空）时：✅ 正确句行不展示，「复制」按钮降级为复制原句或禁用并提示，跟读面板以原句为播放文本，均不报错
- 首次点击发音按钮时后端合成需要等待：按钮呈加载态，用户可感知；等待期间重复点击不重复发起合成
- 页面刷新或切换会话后回到含纠错气泡的对话：气泡按默认展开态恢复渲染（与原型图一致），样式正确无错乱
- 同屏多条纠错气泡：各自独立展开/收起互不影响；音频播放全局互斥（播放任一条的音频时，其他气泡与跟读面板的声音自动停止）
- 跟读面板打开状态下用户发送新消息：面板行为不受影响，对话能力正常
- 极长原句/正确句：气泡内正常换行，跟读面板全文可滚动查看

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 识别含语法纠错内容的 AI 消息，并按验收基准以专用气泡渲染两种状态——**默认展开态**（原句行 + 功能行 + 讲解内容 + ✅ 正确句行 + 底部操作栏，与原型图一致）与收起态（紧凑两行：原句行 + 功能行）；不影响普通 AI 消息的现有渲染
- **FR-002**: 系统 MUST 提供「‼ 语法纠错」标签（⌄/⌃）的展开/收起交互：收起态仅原句行 + 功能行；展开态显示后端纠错讲解文本、✅ 正确句行与底部操作栏
- **FR-003**: 系统 MUST 提供「复制」交互，点击后仅将改正后的完整英语句子写入剪贴板，并给予复制成功反馈
- **FR-004**: 系统 MUST 提供两个独立的「AI 发音」按钮：功能行的播放用户原句发音，操作栏的播放改正后句子发音；发音音频按需向后端请求合成后播放
- **FR-005**: 系统 MUST 保证音频播放**全局互斥**：任何时刻整个页面最多一段音频在播放（气泡内按钮、跨气泡、跟读面板均包含在内），开始新的播放时自动停止正在播放的音频
- **FR-006**: 系统 MUST 提供「循环跟读」入口，点击后底部弹出跟读面板，面板包含：标题与关闭键、正确句全文、进度条（当前时间/总时长）、暂停/播放键、倍速切换、语言切换选项组、循环播放开/关、底部麦克风跟读按钮，布局与跟读面板原型图一致
- **FR-007**: 跟读面板 MUST 支持倍速切换（至少 0.75x / 1.0x / 1.25x）且切换后播放速度即时生效
- **FR-008**: 跟读面板 MUST 支持循环播放开/关：开启时播放结束自动重播，关闭时播放结束即停
- **FR-009**: 跟读面板 MUST 提供语言切换选项展示（英语(美)/英语(英)/中文等）；对当前后端尚不支持的口音/语言，选项 MUST 以禁用或明确降级提示呈现，不得报错或静默失效
- **FR-010**: 系统 MUST 提供「文A」翻译按钮的展开/收起交互；译文数据可用时显示翻译，不可用时显示明确的暂无翻译提示
- **FR-011**: 系统 MUST 在评分数据可用时于气泡下方展示语法/发音/地道评分条，数值与后端数据一致；数据缺失时对应项不展示；「发音分析 >」「更多地道 >」入口本次为静态占位（轻提示，不跳转，目标界面属后续 feature）
- **FR-012**: 所有音频请求失败场景 MUST 优雅降级（明确提示 + 可重试），不得阻塞文本内容展示，不得导致页面报错
- **FR-013**: 既有功能（创建新对话、HITL 中断回复、选场景弹窗、普通消息收发）MUST 零回归
- **FR-014**: 「收藏」按钮在原型图中存在但本次未指定行为，MUST 以静态占位呈现（可点击但无副作用或轻提示），不报错

### Key Entities *(include if feature involves data)*

- **纠错气泡消息**: 一条含纠错内容的 AI 消息；关联原句文本、纠错讲解文本、正确句条目列表、评分信息
- **正确句条目**: 单条修正（错误片段、修正后完整句子、错误类型）；「复制」「跟读」「正确句发音」均取自修正后完整句子
- **发音资源**: 原句音频与正确句音频，按需向语音合成旁路请求获取；含合成状态（未请求/合成中/可播放/失败）
- **评分信息**: 语法、发音、地道三项分数及其展示文案，来自后端检查结果；各项可独立缺失
- **跟读播放状态**: 播放/暂停、当前进度、总时长、倍速、语言/口音选项、循环开关
