# Quickstart: 子功能-对话演示气泡-语法纠错场景 手动验收指南

**Date**: 2026-10-24 | **Spec**: [spec.md](./spec.md) | **基准**: 展开态 [mockup](../../docs/mockups/子功能-对话演示气泡-语法纠错场景.jpg)、收起态（用户外部截图）、跟读面板（spec US4/FR-006 文字描述）

## 前置准备

```powershell
# 终端 A：后端（根目录执行，自带 PYTHONUTF8=1）
pnpm dev:backend          # API: http://127.0.0.1:2024

# 终端 B：前端
pnpm dev:frontend         # http://localhost:3000
```

浏览器打开 http://localhost:3000，进入 Tab1 自由对话主页。准备一句含语法错误的英语（如 `she go to school yesterday`）。

## §0 契约透传验证（implement 第一验收步）

1. 发送错误句，等 AI 回复。
2. F12 → Console 检查该 AI 消息对象：存在 `correction_data`（raw_text/tutor_reply/corrections）→ **通过**。
3. 若丢失 → 按 contracts/correction-message-contract.md 的 Fallback 处理并记录。

## §1 US1 气泡渲染与展开/收起

1. 收到回复后气泡**默认展开态**：原句行 + 功能行（文A / ‼语法纠错 ⌃ / AI）+ 中文讲解 + ✅ 正确句 + 操作栏（循环跟读/复制/收藏/AI）——与 mockup 目视比对一致。
2. 点击「‼语法纠错 ⌃」→ 收起为紧凑两行（原句行 + 功能行，⌄），与收起态截图一致；再点 → 展开复原。
3. 发送一句**完全正确**的英语 → 回复为普通气泡样式，与本功能上线前一致（零回归）。
4. 检查评分条：有发音评分时气泡下方出现「发音 x 发音分析 >」；无数据项不出现、不报错。

## §2 US2 复制

1. 展开态点「复制」→ 按钮出现对勾反馈。
2. 在任意文本框 Ctrl+V → 粘贴内容 = 完整正确英语句，无讲解/原句/多余字符。

## §3 US3 双 AI 发音

1. 点功能行「AI」→ 加载态 → 播放**原句**朗读。
2. 播放中点操作栏「AI」→ 原句声音立即停止，播放**正确句**朗读。
3. 再点一次同一按钮 → 不重复合成，直接重播。
4. （可选）断网/停后端再点 → 友好失败提示、可重试、文本展示不受影响。

## §4 US4 循环跟读面板

1. 点「循环跟读」→ 底部滑入面板：标题「循环跟读」+关闭键、正确句全文、进度条（时间走动）、圆形暂停/播放键、倍速、语言切换、循环开关、底部麦克风按钮——主页对话在面板后方可见。
2. 暂停/继续 → 进度条与时间同步。
3. 切 0.75x / 1.25x → 语速即时变化、音调正常。
4. 开循环 → 播完自动重播；关循环 → 播完即停。
5. 点语言切换 → 英语(美)可用；英语(英)/中文禁用或降级提示，不报错。
6. 点麦克风 → 轻提示（功能开发中），不报错。
7. 点右上关闭 → 面板收回，对话不中断；随后发新消息 → 正常收发。

## §5 US5 文A 翻译

1. 点「文A」→ 展开翻译区域，显示"暂无翻译"占位（后端本期无译文字段），按钮激活态；再点 → 收起。

## §6 FR-013 既有功能回归

依次操作并确认行为与上线前一致：创建新对话、HITL 中断回复（如有触发路径）、选场景弹窗（002 功能）、普通消息收发、录音转写按钮。

## 通过标准

- 各节操作全程无控制台报错、无页面崩溃
- §1 布局与两张基准图目视比对一致（不一致处以原型图为准）
- §6 全部零回归
