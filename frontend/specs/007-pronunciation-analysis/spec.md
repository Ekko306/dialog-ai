## User Scenarios & Testing *(mandatory)*

### User Story 1 - 纠错气泡查看发音分析与评分 (Priority: P1)

纠错气泡（句子有语法错误且用户以语音输入）的用户想深入了解自己读得怎么样：点击评分条「发音」或「地道」任一入口，底部弹出完整面板，自上而下显示三个区块——发音逐词分析（被评测句逐词展示，点「美音」可听示范）、评分建议（综合评分、流利度、发音分、完整度与评语）、语境润色（复用既有地道面板内容）。评测数据在面板打开时按需获取（短暂加载反馈后填充），来源是用户本轮语音录音的评测结果。

**Why this priority**: 本 feature 的核心价值；评测复用既有评测服务能力，零新增评测逻辑。

**Independent Test**: 语音输入含语法错误的英文 → 纠错气泡 → 点「发音」入口 → 完整三区块面板出现（评测加载反馈后填充）；关掉换点「地道」入口 → 打开的是同一内容。

**Acceptance Scenarios**:

1. **Given** 语音输入产生的纠错气泡，**When** 点击评分条「发音」入口，**Then** 底部弹出面板完整显示发音逐词分析、评分建议、语境润色三区块，评测区块先显示加载反馈、就绪后填充
2. **Given** 同一纠错气泡，**When** 点击评分条「地道」入口，**Then** 打开与「发音」入口相同的完整面板（两入口共用一面板）
3. **Given** 面板已打开，**When** 点击逐词分析区的「美音 📢」，**Then** 播报被评测句（用户原句）的美音示范读音
4. **Given** 面板已打开，**When** 点击 × 或遮罩，**Then** 面板关闭；再次打开内容一致

---

### User Story 2 - 重读刷新评分 (Priority: P2)

用户对当前评分不满意想再试一次：点击「↻ 重读」，面板内弹出录音操作区，用户朗读纠正句后确认结束，系统重新评测，评分建议区块以新结果刷新（逐词分析同步更新）；新评分仅在面板内生效，气泡评分条保持原样。

**Why this priority**: 闭环学习的关键交互，但依赖录音采集与按需评测链路（技术依赖重于 US1），排后。

**Independent Test**: 打开面板 → 点「↻ 重读」→ 出现录音操作 → 朗读并结束 → 评分建议数值更新为最新评测结果；关闭面板重开，气泡评分条未变。

**Acceptance Scenarios**:

1. **Given** 面板已打开且存在评测数据，**When** 点击「↻ 重读」，**Then** 面板内出现录音操作区（开始/结束控制，参考文本为纠正句）
2. **Given** 录音操作区已显示，**When** 用户完成朗读并确认结束，**Then** 显示评测进行中反馈，随后评分建议区块与逐词分析以新评测结果刷新
3. **Given** 评测进行中，**When** 用户取消录音或关闭录音区，**Then** 面板回到重读前状态，无残留
4. **Given** 重读评测失败，**When** 用户点击行内重试，**Then** 可重新发起评测；成功后正常刷新

---

### User Story 3 - 数据降级与零回归 (Priority: P3)

非语音输入（文本打字）产生的纠错气泡没有评测数据：面板仍可打开，但发音逐词分析与评分建议区块不显示（或显示明确的无数据说明），语境润色区块照常可用；同时 003/004/005/006 既有行为全部保持。

**Why this priority**: 保证功能在数据不全时不破相，以及保护既有 feature 的稳定，属质量底线。

**Independent Test**: 文本输入含语法错误的英文 → 打开面板 → 仅语境润色区块可用且发音区块有明确的降级表现；复测 003~006 验收场景全部通过。

**Acceptance Scenarios**:

1. **Given** 文本输入产生的纠错气泡，**When** 点击「发音」/「地道」入口，**Then** 面板打开且语境润色区块正常；发音逐词分析与评分建议区块不渲染错误数据，给出无评测数据的表现
2. **Given** 面板在无评测数据场景，**When** 查看「↻ 重读」入口，**Then** 重读入口不出现（无参考评分时重读无意义）
3. **Given** 本功能已部署，**When** 复测 003/004/005/006 既有验收场景，**Then** 全部保持通过

---

### Edge Cases

- 逐词数据与纠正句词数不一致（评测基于原句、展示基于纠正句）→ 逐词分析按评测实际覆盖的词展示，缺失词不着色不标分，不伪造
- 用户拒绝浏览器麦克风权限 → 录音操作区给出明确权限提示，提供关闭途径，面板其余部分不受影响
- 重读录音过短/无声 → 评测端返回失败语义，走失败重试态，不渲染空评分
- 评测结果为「未识别/拒绝」（分数不可信）→ 评分建议按失败语义处理，不展示误导性数字
- 面板打开期间用户点击其他消息的入口 → 各消息面板独立，互不串数据
- 重读进行中关闭面板 → 评测完成结果不写回对话线程与气泡，仅会话内缓存供本次面板会话使用

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 纠错气泡评分条「发音」与「地道」两个入口 MUST 打开同一个完整三区块面板（发音逐词分析 + 评分建议 + 语境润色）；「发音」入口替代既有「发音分析」占位行为
- **FR-002**: 发音逐词分析区块 MUST 展示本轮被评测句（用户原句）的逐词视图，每个词附带本轮评测的单词发音质量标注；音频控制 MUST 仅提供「美音」一路示范播放（英音与「我的」读法按用户拍板不提供）
- **FR-003**: 评分建议区块 MUST 展示综合评分、流利度、发音分、完整度四项分数与评语；分数来源于按需评测结果（首轮 = 本轮录音的评测，重读 = 新录音的评测）
- **FR-004**: 语境润色区块 MUST 复用既有地道面板的展示与操作（优化句、修改解释、操作行四件套），数据规则不变
- **FR-005**: 评分建议区块 MUST 提供「↻ 重读」操作：点击后面板内出现录音操作区，用户完成朗读并确认后重新评测，评分建议与逐词分析以新结果刷新；新结果 MUST NOT 回写气泡评分条、MUST NOT 写入对话线程
- **FR-006**: 录音操作区 MUST 提供开始与结束控制、明确的进行中反馈；评测期间 MUST 显示加载反馈；失败 MUST 提供行内重试
- **FR-007**: 无评测数据（如文本输入）时，面板 MUST 仍可打开且语境润色区块照常；发音逐词分析、评分建议、重读入口 MUST 给出无数据的降级表现而非渲染空壳或报错
- **FR-008**: 逐词分析 MUST 仅基于真实评测数据渲染；评测未覆盖的词 MUST NOT 伪造分数或颜色标注
- **FR-009**: 面板 MUST 支持点击 × 与点击遮罩两种关闭方式；再次打开时内容与关闭前一致（重读新结果在会话内保持）
- **FR-010**: 本功能 MUST NOT 影响 003/004/005/006 气泡与面板的既有渲染、操作与降级行为（零回归）
- **FR-011**: 重读评测 MUST 优先复用既有评测服务能力按需获取；若现有后端无按需评测入口，MUST 采用最小适配方案并在实施计划中留档，适配范围仅限新增按需评测通路，不改既有节点行为

### Key Entities *(include if feature involves data)*

- **发音评测数据**: 纠正句（参考文本）、逐词发音质量列表（词 + 质量标注）、四项分数（综合/流利度/发音分/完整度）、评语；来源为本轮语音输入评测结果或重读新评测结果
- **面板展示状态**: 三区块各自的数据可用性（有评测数据 / 无评测数据 / 评测中 / 失败可重试）
- **重读会话结果**: 以消息标识关联的最近一次重读评测结果，仅面板内消费

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 语音输入纠错气泡点击任一入口后，三区块面板在 1 秒内可见（语境润色区块即时渲染；评测区块显示加载反馈，评测结果就绪后填充，评测耗时与语音评测服务一致）
- **SC-002**: 重读从点击「↻」到新评分显示的流程可顺利完成，评测等待期间始终有可见反馈；成功率 ≥ 90%
- **SC-003**: 文本输入场景面板打开无报错、无空壳渲染，降级表现明确
- **SC-004**: 003/004/005/006 既有人工验收场景复测全部通过（零回归）

## Assumptions

- **数据源勘误（plan 探查结论，2026-10-27）**：聊天主链 run 不携带音频（语音输入经独立转写后仅文本进对话），本轮 state 无评测数据 → 首评与重读统一走按需评测旁路；本轮录音由前端会话内暂存（按转写文本关联），刷新/历史消息后录音不可得 → 落入 FR-007 降级
- 逐词分析与评分建议以按需评测的确定性解析结果为准；中文逐词点评（后端 LLM 点评产物）作为增强层，有则叠加、无则不显示
- 逐词视图展示的是**用户原句**（评测对象），美音示范播原句；纠正后的句子仅用于语境润色区块（与 006 行为一致）
- 「语速」类原型图中的额外指标若现有评测解析未覆盖，本期不展示（后置）
- 发音逐词分析以「美音示范播放 + 逐词质量标注」形态交付；不提供英音与「我的」回放（用户 2026-10-27 拍板：原型的英音/我的两路删除）
- 重读 = 重新录音 + 重新评测，仅影响面板内显示；原始对话轮次的评测结果与气泡评分条不回写不覆盖
- 重读链路的录音采集与按需评测在前端完成采集，评测能力复用后端既有服务；若需暴露按需评测入口，采用与既有懒加载旁路同构的最小适配并在 plan 留档（用户已确认"尽量不改后端"，适配范围以 FR-011 为界）
- 语境润色区块直接复用 006 已交付的 IdiomPanel 内容与操作，本 feature 不改动其行为
- 浏览器录音依赖用户授权麦克风权限；权限被拒属 Edge Case 处理，不阻塞面板其余功能
- 重读与首评使用同一按需评测通路（最小后端适配点见 plan 留档：新增与既有转写端点同构的评测端点，复用既有评测工具与解析函数，不碰任何 graph/节点）
