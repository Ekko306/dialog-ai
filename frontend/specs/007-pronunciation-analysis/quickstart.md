# Quickstart: 发音逐词分析面板人工验收

**Feature**: 007-pronunciation-analysis | **Prereq**: 后端 127.0.0.1:2024 + 前端 localhost:3000（`pnpm dev:backend` + `pnpm dev:frontend`）；**必须用 http://localhost（非局域网 IP）**，麦克风 API 仅安全上下文可用

## §1 US1 完整三区块面板（语音输入路径）

1. 点输入框麦克风按钮 → 朗读含语法错误的句子（如 "I goes to school yesterday"）→ 结束 → 文本回填 → 发送
2. 纠错气泡出现 → 点评分条「发音」或「地道」任一入口
3. **期望**：底部弹出完整面板，自上而下：
   - 发音逐词分析：原句逐词着色/标注 + 「美音 📢」单路音频按钮（无英音、无「我的」）
   - 评分建议：综合/流利度/发音分/完整度四项 + 「↻ 重读」
   - 语境润色：优化句 + 操作行（复用 006）
4. 评测区块先显示「评测中…」加载反馈（约 1~2s）后填充
5. 点「美音 📢」→ 播**原句**美音示范（与气泡工具栏「发音」同一段，不重复合成）
6. × / 遮罩关闭 → 重开 → 内容一致（缓存命中零请求）
7. 两个入口打开的面板内容一致

## §2 US2 重读刷新

1. 面板内点「↻ 重读」→ 录音操作区出现（开始控制）
2. 开始 → 朗读同一句 → 结束 → 「评测中…」→ 评分建议 + 逐词分析刷新为新结果
3. 关闭面板 → 气泡评分条数值**保持原样**（不回写）；对话线程无新消息
4. 重开面板 → 显示重读后的新结果（会话缓存）
5. 重读中点取消 → 回到先前状态，无残留
6. Edge：拒绝麦克风权限 → 明确提示且面板其余区块可用；录音 <300ms → 失败重试态

## §3 US3 降级

- **文本输入**（打字）含语法错误的句子 → 纠错气泡 → 打开面板 → 语境润色正常；发音区显示无录音降级文案；重读入口不出现
- **刷新后**打开历史语音消息面板 → 同降级（录音已清）
- 语音但 PCM 查不到（发送前改过文本）→ 「未找到本次录音」降级

## §4 零回归（003/004/005/006 复测）

- 纠错气泡：讲解/操作行/TTS/翻译/收藏提示照旧；评分条语法/发音项渲染不变（ise_grade 逻辑零改动）
- 润色气泡：气泡、地道面板（单区块模式）、五操作入口照旧
- 无语法错误语音输入 → 仍出润色气泡（不因 007 出错）
- 普通闲聊 → 正常消息

## §5 端点契约直验（可选，curl）

```powershell
# 200 路径：16kHz PCM 文件（可用现有测试素材）+ ref_text
curl.exe -s -X POST "http://127.0.0.1:2024/audio/evaluate?ref_text=I%20goes%20to%20school" -H "Content-Type: application/octet-stream" --data-binary "@test.pcm"
# 期望：{"total":...,"accuracy":...,"fluency":...,"integrity":...,"is_rejected":false,"words":[...]}

# 400：过短音频；422：缺 ref_text；415：错误 Content-Type
curl.exe -s -o NUL -w "%{http_code}" -X POST "http://127.0.0.1:2024/audio/evaluate" -H "Content-Type: application/octet-stream" --data-binary "xx"
# 期望：400
```
