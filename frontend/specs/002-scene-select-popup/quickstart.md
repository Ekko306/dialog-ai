## 0. 前置条件与环境启动

```powershell
# 后端（backend/ 下，项目 venv + 两个必须参数，见项目约定）
cd e:\dialog-ai-main\backend
$env:PYTHONUTF8=1
uv run langgraph dev --no-reload     # LangGraph Server :2024，确认 talk_agent 图加载成功

# 前端（frontend/ 下，另开终端）
cd e:\dialog-ai-main\frontend
pnpm install
pnpm dev                              # Next.js :3000
```

前端环境变量：`.env.local` 需含 `NEXT_PUBLIC_LANGGRAPH_ASSISTANT_ID=talk_agent`（`LANGGRAPH_API_URL` 默认走 `/api` 代理，参照 `.env.example`）。

## 1. US1：打开弹窗并浏览（P1）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1.1 | 进入 Tab1 主页，点击底部"选场景"入口 | 弹窗从底部滑出；标题"选择场景或角色"右上角有 ×；背后主页仍可见 |
| 1.2 | 查看分类栏 | 5 个胶囊：热门（绿色高亮）/今日话题/日常交流/旅游出行/职场；**热门默认选中** |
| 1.3 | 左右滑动分类栏 | 可横向滚动到被遮挡的"职场" |
| 1.4 | 点击"今日话题" | 卡片即时切换为该分类内容，无刷新 |
| 1.5 | 纵向滚动卡片区 | 超出可视区可滚动；底部"自定义场景/角色"按钮固定不随滚动 |
| 1.6 | 点击 × / 遮罩 | 弹窗收回，主页对话状态不变 |
| 1.7 | 再次打开弹窗 | 回到默认态：热门选中、无卡片选中标记（clarify 决策③） |

## 2. US2：选场景生效 + 兼容零回归（P2）

| 步骤 | 操作 | 预期 |
|------|------|------|
| 2.1 | 先点"新会话"建立对话（教练出话题后停在输入区），再打开弹窗点"求职面试"卡片 | 弹窗关闭；无报错；对话流中**不出现** `_set_context_` 字样 |
| 2.2 | 等待自动续跑的下一轮教练回复 | 回复内容贴合求职面试场景（人工判读，SC-002） |
| 2.3 | 打开弹窗换选"办理登机"，再点"新会话" | 新对话话题沿用/衔接最近选择的场景逻辑正常，无回归 |
| 2.4 | 刷新页面后继续对话 | 场景仍生效（Store 持久化，FR-014） |
| 2.5 | 在输入区应答一次 HITL（正常文本） | 应答正常走语法检查/纠错链路，与选场景前一致 |
| 2.6 | 点击"新会话"（interrupt 态，触发 `_new_context_` 轮换） | 轮换行为与既有完全一致（两者并存，clarify 决策①） |
| 2.7 | 消息流检查 | 自己的消息与后端回复展示正常（SC-003） |

**后端验证（可选，LangSmith Studio / 日志）**：`set_context_node` logger 输出 `role/scenario` 切换记录；Store 命名空间 `("coach_context",)` 的 `current` 值已更新。

**前端验证（可选）**：在任意组件内用 `useLangChainState<string>("scenario")` 读取图状态，选场景后下一轮 run 开始时值变为所选场景。

## 3. US3：UI 目视比对原型图（P2）

弹窗打开状态下与原型图并排逐项核对：

- [ ] 弹窗：白色底、顶部大圆角、贴底滑出、标题栏左标题右 ×
- [ ] 分类胶囊：选中=绿色高亮胶囊，未选中=浅色胶囊；横向滑动
- [ ] 卡片：双列、浅色圆角、emoji 图标居中、下方中文+英文排版
- [ ] 底部按钮：浅绿胶囊"自定义场景/角色"固定于弹窗底部
- [ ] 主页底部输入框与按钮区样式与原型图风格一致（圆角、配色）

不一致处以原型图为准（Constitution 原则 IV）。

## 5. 边界用例抽查（spec Edge Cases）

| 用例 | 操作 | 预期 |
|------|------|------|
| 快速反复开合 | 连续快速点击入口/× | 弹窗状态不错乱、无多层叠加 |
| 运行中选场景 | 教练回复流式输出中打开弹窗选卡片 | 指令暂存，本轮结束后自动应用；期间对话不中断 |
| HITL 挂起时选场景 | 停在输入区时选场景 | 场景生效并续跑；InterruptPrompt 应答路径仍可用 |
| 停服务选场景 | 停掉后端 → 选场景 | 弹窗关闭、出现可感知失败提示、对话恢复后原场景保持（FR-013） |
| 空分类 | 临时清空某分类静态数据 | 显示空态提示，不崩溃 |

## 6. 已知边界（非缺陷）

- 冷启动（尚无任何对话时）先选场景再点"新会话"：首轮教练话题为默认场景，第二轮起生效（research.md R1 已记录的 v1 取舍）。
- 在"是否生成语音"的 audio_choice 中断上选场景：本轮跳过语音询问直接按新场景收尾（research.md R2 既定行为）。
