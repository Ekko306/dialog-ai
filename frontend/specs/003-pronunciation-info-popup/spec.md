# Feature Specification: 发音逐词分析信息弹窗（单击气泡"发音/地道"弹出）

**Feature Branch**: `003-pronunciation-info-popup`（实际工作分支：`zzl-pure`）

**Created**: 2026-10-27

**Status**: Draft

**Input**: 用户指定原型图：`frontend/docs/mockups/子功能-对话演示气泡-单击发音或地道-弹出更多信息弹窗.jpg`。功能描述：在对话演示气泡上单击"发音"或"地道"按钮后，弹出"发音逐词分析"信息弹窗。弹窗包含三大区块：发音逐词分析（逐词着色 + 三音源播放 + 重读）、评分建议（综合评分 + 三维度进度条 + 语速仪表盘 + 文字建议）、语境润色（三风格 Tab + 循环跟读/复制/收藏/AI 朗读 + 修改解释 + AI 生成标注）。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 从气泡打开弹窗并查看逐词发音分析 (Priority: P1)

用户在对话气泡上看到自己刚朗读的句子后，单击气泡上的"发音"（或"地道"）入口，弹出"发音逐词分析"弹窗。弹窗顶部展示该句的逐词着色结果：每个单词按评测质量以颜色区分（待提高/小瑕疵/很完美），特殊发音现象（连读、重读词）有独立标注样式；顶部图例与句中标注一一对应。用户点击"英音""美音"可听示范读音，点击"我的"回放自己的录音，点击"↻重读"重新播放整句示范，从而明确知道"哪个词读得不好、好的读法是什么"。

**Why this priority**: 这是弹窗的核心价值——把不可见的发音质量变成可视、可听的逐词反馈；没有它弹窗无存在意义。

**Independent Test**: 准备一条带评测结果的对话气泡 → 单击"发音"→ 弹窗出现且逐词着色与图例一致 → 依次点击三个播放源均有声音 → 点击"↻重读"重新播放。

**Acceptance Scenarios**:

1. **Given** 对话气泡带有本轮朗读的评测结果，**When** 用户单击气泡上的"发音"入口，**Then** "发音逐词分析"弹窗出现，句子按词着色展示，顶部图例五项（待提高/小瑕疵/很完美/连读/重读词）齐全。
2. **Given** 弹窗已打开，**When** 用户点击"英音"或"美音"，**Then** 播放对应口音的整句示范读音。
3. **Given** 弹窗已打开且本轮有用户录音，**When** 用户点击"我的"，**Then** 回放用户自己的朗读录音。
4. **Given** 弹窗已打开，**When** 用户点击"↻重读"，**Then** 重新播放整句示范读音。
5. **Given** 弹窗已打开，**When** 用户点击右上角 ×，**Then** 弹窗关闭回到对话界面，再次打开时各区块回到默认态。

---

### User Story 2 - 查看评分建议与语速仪表盘 (Priority: P1)

用户在弹窗中部查看量化评分：综合评分徽章、流利度/发音分/完整度三条进度条、语速仪表盘（当前语速词/分，Slow→Fast 弧形刻度），以及针对本轮朗读的中文文字改进建议。用户不用懂评测技术细节，就能知道"总体几分、弱项是什么、下一步练什么"。

**Why this priority**: 量化反馈是用户坚持练习的动力来源，与逐词分析同属弹窗核心价值。

**Independent Test**: 打开弹窗 → 综合评分、三条进度条、语速仪表盘均展示且数值与评测结果一致 → 中文建议列表可见。

**Acceptance Scenarios**:

1. **Given** 评测结果包含各维度分值，**When** 用户查看评分建议区块，**Then** 综合评分徽章与流利度/发音分/完整度三条进度条展示，数值与评测结果一致，进度条长短反映分值高低。
2. **Given** 评测结果包含语速数据，**When** 用户查看语速仪表盘，**Then** 仪表盘显示当前语速（词/分），指针位置反映语速在 Slow→Fast 区间中的位置。
3. **Given** 评测结果包含文字建议，**When** 用户查看建议列表，**Then** 中文改进建议逐条展示、可完整阅读。

---

### User Story 3 - 查看语境润色的多风格改写 (Priority: P2)

用户在弹窗底部"语境润色"区块查看句子的 AI 改写：默认展示"地道美式"风格的优化后句子与中文修改解释（改了什么、为什么改）；可切换"商务正式""地道英式"查看其他风格；可使用循环跟读、复制、收藏、AI 朗读四个工具。底部有"内容由 AI 生成"标注。

**Why this priority**: 润色扩展"怎么说更好"，价值高但依赖逐词分析/评分之外的另一条数据链路，且三风格生成成本更高，故列 P2。

**Independent Test**: 打开弹窗 → 语境润色区块默认"地道美式"选中并展示优化句+解释 → 切换另两个风格内容随之更新 → 复制/收藏/朗读/循环跟读各工具可用。

**Acceptance Scenarios**:

1. **Given** 本轮朗读有润色结果，**When** 用户查看语境润色区块，**Then** 默认"地道美式"Tab 选中（下划线高亮），展示优化后的句子与中文修改解释。
2. **Given** 弹窗已打开，**When** 用户点击"商务正式"或"地道英式"Tab，**Then** 优化句子与解释切换为对应风格内容，无需刷新。
3. **Given** 弹窗已打开，**When** 用户点击复制，**Then** 优化后的句子进入剪贴板并有可见成功反馈；点击收藏后该句被保存且有状态标记。
4. **Given** 弹窗已打开，**When** 用户点击 AI 朗读或循环跟读，**Then** 播放优化后句子的朗读；循环跟读开启后反复播放直到再次关闭。
5. **Given** 弹窗已打开，**When** 用户查看区块底部，**Then** 可见"内容由 AI 生成"标注。

### Edge Cases

- 本轮朗读没有评测数据（用户跳过朗读/评测失败）时单击入口 → 弹窗打开但对应区块显示诚实的空态提示（如"本轮没有评测数据"），不白屏、不展示虚构数值。
- 某风格润色生成失败或缺失时切换对应 Tab → 该 Tab 展示空态提示，不展示错误风格的内容，不影响其他风格。
- 极长句子 → 逐词着色区域可换行/滚动，不溢出弹窗；评分与润色区块正常排版。
- 播放源不可用（如"我的"无本轮录音、某口音合成暂不可用）→ 对应播放控件置灰或点击后给出提示，不静默失败。
- 弹窗打开期间新消息到达 → 弹窗内容保持打开时刻的数据快照，不被后台刷新打断。
- 重复快速开关弹窗 → 无状态残留（Tab 回默认选中、播放停止）。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 对话演示气泡 MUST 提供"发音"与"地道"两个入口；单击任一入口打开"发音逐词分析"弹窗（两个入口指向同一弹窗）。
- **FR-002**: 弹窗 MUST 以卡片分区块呈现三大内容：发音逐词分析、评分建议、语境润色，布局与层级对照原型图。
- **FR-003**: 发音逐词分析 MUST 按评测结果对句子逐词着色标注，标注类别为五类：待提高、小瑕疵、很完美、连读、重读词。
- **FR-004**: 逐词分析区块顶部 MUST 展示五类图例，图例样式与句中标注视觉一致，用户无需额外学习即可对应。
- **FR-005**: 发音分析区块 MUST 提供三个播放源：英音示范、美音示范、我的（用户本轮录音回放），各自可独立触发播放。
- **FR-006**: 发音分析区块 MUST 提供"↻重读"按钮，重新播放整句示范读音。
- **FR-007**: 评分建议区块 MUST 展示综合评分徽章，以及流利度、发音分、完整度三条带数值的进度条。
- **FR-008**: 评分建议区块 MUST 展示语速仪表盘：当前语速（词/分）数值 + Slow→Fast 弧形刻度，指针/填充位置反映语速高低。
- **FR-009**: 评分建议区块 MUST 展示中文文字改进建议列表（逐条可读）。
- **FR-010**: 语境润色区块 MUST 提供三个风格 Tab：地道美式（默认选中）、商务正式、地道英式，切换时更新优化句子与解释。
- **FR-011**: 语境润色区块 MUST 展示优化后的句子与中文修改解释（改了什么、为什么改）。
- **FR-012**: 语境润色区块 MUST 提供四个工具：循环跟读、复制、收藏、AI 朗读，各有可感知的触发反馈（复制成功提示、收藏状态标记、播放启停）。
- **FR-013**: 语境润色区块底部 MUST 展示"内容由 AI 生成"标注。
- **FR-014**: 弹窗 MUST 提供关闭方式（右上角 ×），关闭后回到对话界面；再次打开时回到默认态（地道美式 Tab 选中、播放停止）。
- **FR-015**: 缺失数据时 MUST 降级展示：无评测数据显示空态提示，播放源不可用时控件置灰或给出提示，MUST NOT 展示虚构数值或静默失败。
- **FR-016**: 发音与评分数据 MUST 复用后端既有发音评测产出；润色内容 MUST 复用后端既有润色链路；后端仅允许联调必需的最小适配（字段透出/格式适配），MUST NOT 改动 Agent 核心逻辑（Constitution 原则 II/III）。

### Key Entities *(include if feature involves data)*

- **逐词发音标注**：句中每个单词的质量类别（待提高/小瑕疵/很完美）与特殊现象标记（连读/重读词）；来源于后端发音评测的逐词结果。
- **评分建议集**：综合评分、流利度、发音分、完整度（均为分值）、语速（词/分）、中文建议文本列表；来源于后端评测产出。
- **润色结果**：按风格区分（地道美式/商务正式/地道英式）的优化后句子 + 中文修改解释；三种风格由后端润色链路一次性生成（Clarifications Q1 决策 A）；个别风格生成失败时按 Edge Cases 降级。
- **播放源**：英音示范音频、美音示范音频、用户本轮录音；示范音频按需合成，用户录音来自本轮语音输入。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户单击气泡入口后，弹窗在 1 秒内完整呈现（已加载数据场景），无感等待。
- **SC-002**: 逐词标注与顶部图例五类一一对应，抽查验读无误标、无歧义配色。
- **SC-003**: 用户点击任一可用播放源后 2 秒内听到声音；"↻重读"每次点击均有播放响应。
- **SC-004**: 评分区块展示的综合评分、三维度分值、语速与后端评测产出数值完全一致，无四舍五入错位。
- **SC-005**: 三个风格 Tab 切换即时生效（无需刷新页面），选中态视觉清晰。
- **SC-006**: 全部降级场景（无评测数据、无录音、风格缺失）均有可见反馈，验收抽查零白屏、零虚构数值。
- **SC-007**: 弹窗界面效果与原型图目视比对一致（布局、配色、标注样式、文案），不一致处以原型图为准。

## Assumptions

- 对话气泡上的"发音"与"地道"两个入口打开同一个弹窗；"发音"入口默认视觉聚焦逐词分析区块，"地道"入口默认聚焦语境润色区块（仅滚动定位差异，不改变内容）。
- "↻重读"语义为重新播放整句示范读音（与英音/美音同源）。
- 英音/美音示范读音按需合成（依赖 TTS 支持对应英文口音）；若某口音暂不可用，按 FR-015 降级。
- 弹窗展示的是"打开时刻"的数据快照；历史气泡若无对应评测/录音数据，按 FR-015 空态处理。
- 收藏功能先做内存态标记（本次会话内可见状态），持久化收藏列表不在本功能范围内。

## Dependencies

- 后端既有发音评测链路（逐词结果、评分、语速、建议文本均已产出）。
- 后端既有润色链路（润色结果与中文解释）。
- 原型图：`frontend/docs/mockups/子功能-对话演示气泡-单击发音或地道-弹出更多信息弹窗.jpg`（需求与验收的视觉基准）。

## Clarifications *(已裁决)*

- **Q1（润色三风格数据来源）→ 决策 A（2026-10-27，用户确认）**：后端润色链路**一次性生成三种风格**（地道美式/商务正式/地道英式），前端三 Tab 直接消费已有数据。后端改动限于润色输出 schema 与提示词的风格扩展（最小适配，Constitution 原则 II 允许），MUST NOT 改动图结构与节点逻辑。个别风格生成失败时按 Edge Cases 降级。
