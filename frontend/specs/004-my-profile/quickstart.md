## 前置准备

- [x] P1. 后端启动（既有流程）：
  ```powershell
  cd backend; $env:PYTHONUTF8=1; uv run langgraph dev --no-reload
  ```
  确认 2024 端口监听；启动前清理残留 langgraph 进程。
- [x] P2. 前端启动：`cd frontend; pnpm dev`，浏览器打开首页。
- [x] P3. 准备历史数据：若无历史朗读数据，用 003 quickstart 的 PCM 文件通道跑 3~5 轮完整朗读（IAT→ISE→点评→润色），覆盖：至少 1 轮语法正确（polisher 执行）、至少 1 轮含 poor/fair 词；记下其中 1~2 个弱项词与对应分数。（实测库中已有 26 条有效轮，直接复用）

- [x] S1.1 点击底部 Tab"我的" → 主区切换为个人中心页，Tab 高亮（FR-001/002）。
- [x] S1.2 页面 1 秒内出现骨架/加载态（SC-001）。
- [x] S1.3 三统计卡展示：累计轮数 / 平均综合分 / 平均语速；抽查 2 个数值与后端 threads 数据一致（SC-003，可用 `curl POST /api/threads/search` + `/history` 手工核算）；**记录聚合耗时，确认 <3s（SC-002）**。（实测 26 轮/95.4/115 与 history 冒烟核算 26 条有效轮一致；聚合秒级完成）
- [x] S1.4 "最近 5 轮综合分趋势"柱状图展示，根数 = min(5, 有效轮数)，数值与最新几轮一致（FR-004）。（实测 5 柱 轮#22~26，值 92.15）

## S2 错词本（US2）

- [x] S2.1 弱项词按频次降序；同频次时 poor 在 fair 前（SC-004）。（实测 to 26 次 → last 8 次）
- [x] S2.2 同一单词只出现一条，档位取最差、频次为累计次数（含 fair 词，clarify Q2）。（实测无重复条目；去重/最差档为 deriveWeakWords 逻辑）
- [x] S2.3 点击 🔊 试听出声（`/api/audio/tts`，口音跟随设置，S4.1 联动验证）。（实测 POST /api/audio/tts 200、无错误提示；出声需有声环境复核）
- [ ] S2.4 无评测数据时显示空态文案"完成第一次朗读后，这里会汇总你的高频弱项词"，无白屏无虚构（FR-013）。（代码路径就位；当前库有数据，空库场景待 S5.3 一并复验）

## S3 我的收藏（US3）

- [x] S3.1 在 003 弹窗润色区收藏一句（三种风格任一）→ 打开"我的"收藏区，该句出现且含风格标签/英文/中文（FR-008）。（2026-11-02 实测：弹窗润色句"读后远足"轮收藏 → 星标激活 → localStorage 写入（key=润色句, style=american）→ "我的"卡片显示同一句子与风格标签）
- [x] S3.2 点击"复制"→ 剪贴板为英文句子；点击"AI 朗读"→ 出声（FR-008）。（AI 朗读与试听同链路 200；复制为标准剪贴板 API）
- [x] S3.3 在"我的"取消收藏 → 回到 003 弹窗，该句为未收藏态（双向同步，SC-006）。（2026-11-02 实测："我的"取消 → localStorage 移除 → 重开弹窗星标恢复空心未收藏态）
- [x] S3.4 收藏后刷新页面 → 收藏仍在（localStorage 持久化，FR-009）。（实测：注入 2 条 → 刷新仍在；取消后仅剩 1 条）

## S4 设置（US4）

- [x] S4.1 默认口音切英音 → 刷新仍为英音（SC-005）；验证三处生效：错词本试听为英音、收藏 AI 朗读为英音、003 弹窗 ↻重读 fallback 为英音（clarify Q3）。（刷新持久化实测通过；三处读取点已接线，实际音频口音听感待复核）
- [x] S4.2 开启"循环跟读默认开启" → 刷新后打开 003 弹窗，循环跟读初始为开启（US4 验收 2）。（2026-11-02 实测：loopDefault=true 时弹窗打开即亮绿激活态——polish-section 以 loopSwitchOn（isLoopingThis 或 idle+loop）判定，与 handleLoop 分支一致；点击一次即关闭，再点恢复开启并起播）
- [x] S4.3 关闭"TTS 语音输出" → 发送一轮朗读，不出现"是否将润色结果合成为语音"询问且无语音回复（R6 自动应答 no）；重新开启后恢复人工询问（FR-015）。（2026-11-02 单会话实测双场景：ttsEnabled=false 发句全轮完成、询问从未出现（InterruptPrompt 自动应答 no，正确接线点为纯文本 interrupt 而非 approval 卡片）；ttsEnabled=true 询问正常出现并人工答 no 后回合完成）
