## User Scenarios & Testing *(mandatory)*

### User Story 1 - 润色气泡查看地道表达 (Priority: P1)

用户在润色气泡（语法正确但表达可优化）上想学习更地道的说法：点击评分条上的「地道」入口，底部弹出面板展示「优化后的句子」与「修改解释」，并可通过操作行跟读、复制、发音。润色结果已随消息透传，弹窗内容即时呈现、无等待。

**Why this priority**: 数据已随 005 消息透传，零网络等待即可交付完整学习价值；同时建立弹窗壳组件，供 US2 复用。

**Independent Test**: 发一句语法正确、可润色的英文 → 润色气泡出现 → 点「地道」入口 → 弹窗即时显示润色内容；关闭重开内容保持。

**Acceptance Scenarios**:

1. **Given** 润色气泡已渲染（含润色建议），**When** 点击评分条「地道」入口，**Then** 底部弹出面板仅含语境润色区块：优化后的句子、修改解释、风格标签栏（默认「地道美式」高亮）、操作行四件套
2. **Given** 弹窗已打开，**When** 点击 × 按钮或面板外遮罩，**Then** 面板关闭，页面恢复弹窗前状态
3. **Given** 弹窗关闭后，**When** 再次点击入口，**Then** 面板再次打开且内容与上次一致，无加载过程

---

### User Story 2 - 纠错气泡按需生成地道表达 (Priority: P2)

纠错气泡（句子有语法错误已被纠正）的用户想看纠正句的地道变体：点击评分条「地道」入口，面板打开并显示加载反馈，以纠正后的句子为输入现场生成润色结果，完成后显示优化句与解释；结果会话内缓存，重开不再等待。

**Why this priority**: 纠错场景的地道学习价值高，但依赖按需生成（存在网络与生成等待），排在即时数据的 US1 之后。

**Independent Test**: 发语法错误句 → 纠错气泡出现 → 点「地道」入口 → 加载反馈 → 显示针对纠正句的润色内容；关闭重开立即显示缓存结果。

**Acceptance Scenarios**:

1. **Given** 纠错气泡已渲染且存在纠正句，**When** 点击「地道」入口，**Then** 面板打开并显示明确的加载中反馈
2. **Given** 加载中，**When** 按需生成成功，**Then** 显示针对纠正句的优化句子与修改解释
3. **Given** 生成失败，**When** 用户点击行内重试，**Then** 重新发起生成；成功后正常显示
4. **Given** 本消息已成功生成过，**When** 关闭面板再次打开，**Then** 立即显示缓存结果，无加载态、不重复发起生成

---

### User Story 3 - 弹窗操作能力与零回归 (Priority: P3)

弹窗操作行四个操作全部作用于当前展示的润色句：循环跟读（打开跟读面板）、复制（写入剪贴板 + 成功反馈）、收藏（占位提示）、AI 发音（播报润色句）。同时保证 003 纠错气泡与 005 润色气泡的既有渲染与操作零回归。

**Why this priority**: 操作能力补齐学习闭环，但依赖 US1/US2 交付的弹窗存在；零回归是质量底线而非独立价值。

**Independent Test**: 在 US1 的弹窗中逐一点击四个操作验证行为；随后复测 003/005 既有验收场景确认不受影响。

**Acceptance Scenarios**:

1. **Given** 弹窗已显示润色句，**When** 点击循环跟读，**Then** 打开既有跟读面板且跟读对象为润色句
2. **Given** 弹窗已显示润色句，**When** 点击复制，**Then** 剪贴板内容为润色句且出现成功反馈
3. **Given** 弹窗已显示润色句，**When** 点击收藏，**Then** 出现「功能开发中」类占位提示
4. **Given** 弹窗已显示润色句，**When** 点击 AI 发音，**Then** 播报的是润色句（非原句或纠正句）
5. **Given** 本功能已部署，**When** 复测 003/005 既有验收场景，**Then** 全部保持通过

---

### Edge Cases

- 纠错气泡无纠正句（修正列表为空）→ 评分条不显示「地道」入口，无从打开弹窗
- 按需生成期间用户关闭弹窗 → 生成在后台完成并写入会话缓存，再次打开直接显示结果
- 润色气泡消息数据异常（缺字段）→ 既有守卫拦截，气泡本身不渲染，入口无从出现
- 同一会话多条纠错消息分别打开弹窗 → 各消息缓存相互独立，内容不串
- 弹窗打开期间页面滚动/切换会话 → 面板随会话状态正确关闭，不残留遮罩

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 润色气泡 MUST 在评分条区域显示「地道」入口（文案「更多语境」+ 前导箭头，样式按原型图），入口不显示分数数字
- **FR-002**: 纠错气泡 MUST 在评分条区域显示「地道」入口（文案「优化表达」+ 前导箭头，样式按原型图），入口不显示分数数字；仅当存在纠正句时显示
- **FR-003**: 点击任一入口 MUST 弹出底部弹出面板，面板仅含「语境润色」区块：区块标题、风格标签栏、操作行、优化后的句子、修改解释；布局与视觉以原型图语境润色区块为准
- **FR-004**: 润色气泡弹窗 MUST 展示该消息已携带的润色结果（优化后的句子 + 修改解释），即时渲染、无加载态
- **FR-005**: 纠错气泡弹窗 MUST 以纠正后的完整句为输入按需获取润色结果：生成期间 MUST 显示明确加载反馈；按需生成 MUST NOT 写入对话线程、MUST NOT 改变气泡本体内容
- **FR-006**: 按需生成失败 MUST 显示失败态并提供行内重试操作（交互与既有翻译区失败重试一致）
- **FR-007**: 同一消息的按需润色结果 MUST 在会话内缓存；重复打开弹窗 MUST NOT 重复发起生成
- **FR-008**: 风格标签栏展示「地道美式」单项标签（2026-10-27 人工验收拍板：商务正式/地道英式占位删除，多风格后端能力后置）
- **FR-009**: 操作行 MUST 提供循环跟读、复制、收藏、AI 发音四个操作，全部作用于当前弹窗展示的润色句：跟读复用既有跟读面板；复制写入润色句并给成功反馈；收藏给出功能开发中提示；发音复用既有语音合成能力播报润色句
- **FR-010**: 面板 MUST 支持点击 × 按钮与点击遮罩两种关闭方式；关闭后再次打开内容保持一致
- **FR-011**: 本功能 MUST NOT 影响 003 纠错气泡与 005 润色气泡的既有渲染、操作与降级行为（零回归）

### Key Entities *(include if feature involves data)*

- **语境润色展示数据**: 优化后的句子（英文）、修改解释（中文）、风格标签（本期单风格）。润色气泡场景来自消息已携带的润色结果；纠错气泡场景来自按需生成
- **按需润色请求**: 输入为纠正后的完整句；结果以消息标识为键在会话内缓存
- **弹窗入口状态**: 各气泡评分条上的「地道」入口可见性——润色气泡恒显示；纠错气泡以存在纠正句为前提

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 润色气泡点击「地道」入口后，弹窗内容在 1 秒内完整可见（本地数据即时渲染）
- **SC-002**: 纠错气泡按需生成在 10 秒内出结果的比例 ≥ 90%，且生成期间始终有可见加载反馈
- **SC-003**: 弹窗打开/关闭循环 10 次，无布局错乱、无内容丢失；已缓存场景下无重复生成请求
- **SC-004**: 003/004/005 既有人工验收场景复测全部通过（零回归）

## Assumptions

- 原型基准为 docs 既有 mockup 的「语境润色」区块；用户 2026-10-27 提供的四张交互截图明确 006 范围 = 仅语境润色区块，且不入 docs 原型图库（Constitution IV 的原型对照以既有 mockup + 本 spec 描述为准）
- 发音逐词分析 + 评分建议区块不在本 feature 范围，属后续 007 feature（纠错气泡「发音」入口同样后置到 007）
- 多风格润色（商务正式/地道英式）需后端生成能力扩展，本期后置；标签栏仅展示「地道美式」单项（2026-10-27 人工验收拍板）
- 地道分数（原型图中的「地道40/100」）无后端数据源，本期入口不显示分数
- 收藏为占位交互（与 005 行为一致），完整收藏能力另行规划
- 润色气泡弹窗数据依赖 005 已建立的消息透传与会话缓存机制；纠错气泡按需生成依赖既有润色服务能力，接入细节（是否需最小后端适配）在 plan 阶段确认并留档
